## 2. 三层中西医协同设计

```
臻护现有:         新增中医层:
L1-L14 (西医)     L15 (中医核心)     L9 增强(患教)
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 疾病要点  │     │ 六经辨证  │     │ 药食同源  │
│ 临床评分  │     │ 经方速查  │     │ 饮食禁忌  │
│ 药物安全  │     │ 性味归经  │     │ 节气养生  │
│ 检验参考  │     │ 倪氏标准  │     │ 康复指导  │
│ ...       │     │ 脉舌速查  │     │ ...       │
└──────────┘     └──────────┘     └──────────┘

协同模式:
  入院阶段: 西医诊断 + 中医体质辨识 (倪氏六标准)

  出院阶段: 西医患教 + 中医康复/饮食/节气建议 (L9+L15)
```

### 3.2 中西医药物协同检查

在现有 L5(药物安全) 基础上增加:

```
药物相互作用新维度:
  西药+西药 → L5 已有 ✅
  西药+中药 → L15 新增 (如: 华法林+当归→出血风险)
  中药+中药 → L15 新增 (如: 附子+半夏→十八反)
```

实现: 在 `medication_rules.py` 补充中药-西药交互规则, RAG检索自动融合L5+L15

### 3.3 中医体质出院评估

在出院患教(L9)中注入倪氏六健康标准:

```
出院评估:
  西医: NEWS2<5, 体征稳定, 出院标准达标 ✅ 已有
  中医: 六健康标准评估 + 康复建议(饮食/起居/节气)  🆕
  
患教卡片:
  当前: 纯西医 (COPD吸入剂/心衰饮水控制)
  增强: +中医体质调理 (阴虚/阳虚/气虚对应的饮食起居建议)
```
