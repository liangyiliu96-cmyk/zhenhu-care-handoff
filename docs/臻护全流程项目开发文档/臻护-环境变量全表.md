## 一、后端环境变量

### 1.1 核心必填 (3)

| 变量 | 用途 | 默认值 | 示例 | 必填 | 影响 |
|------|------|------|------|:--:|------|
| `DEEPSEEK_API_KEY` | LLM API 密钥 | — | `sk-xxxx` | ✅ | 全部 Agent 节点 + 5 模式助手 |
| `APP_ENV` | 运行环境 | `dev` | `dev` / `staging` / `production` | — | 生产保护、SQLite 限制与管理运维授权 |
| `AUTH_MODE` | 认证模式 | `header` | `header` / `jwt` / `oidc` | — | 全局认证行为 |
| `MANAGEMENT_OPERATIONS_ENABLED` | 生产管理写开关 | `false` | `true` / `false` | production 写操作 | 与管理员 claim 共同决定重建、种子、清理等写操作 |

### 1.2 数据库 (5)

| 变量 | 用途 | 默认值 | 必填 | 说明 |
|------|------|------|:--:|------|
| `STORAGE_BACKEND` | 数据库类型 | `sqlite` | — | `sqlite` (开发) / `mysql` (生产) |
| `DATABASE_URL` | MySQL 连接串 | — | mysql 模式 | `mysql+asyncmy://user:pass@host:3306/db` |
| `DB_POOL_SIZE` | 连接池大小 | `5` | — | 生产建议 20-50 |
| `DB_MAX_OVERFLOW` | 溢出连接数 | `10` | — | SQLAlchemy async engine 溢出连接数 |
| `DB_POOL_RECYCLE` | 连接回收(秒) | `3600` | — | MySQL 长连接回收 |
| `STATE_DB_PATH` | 热状态 SQLite 路径 | 项目默认数据库 | sqlite 模式 | — | 开发状态库路径 |
| `ALLOW_SQLITE_STATE_STORE` | 生产下允许 SQLite 状态库 | `false` | `true` / `false` | 不建议 | 仅用于明确的临时兼容场景 |
| `MYSQL_HOST` 等 | MySQL 热状态连接参数 | 见 state_store 默认值 | MySQL 模式 | 视部署 | `MYSQL_HOST/PORT/USER/PASSWORD/DATABASE` 用于状态库后端 |

## 三、按环境的推荐配置

### dev

```bash
APP_ENV=dev
AUTH_MODE=header
STORAGE_BACKEND=sqlite
DEEPSEEK_API_KEY=<本地密钥>
MILVUS_HOST=127.0.0.1
SKIP_BRIDGE=true
SKIP_EXTERNAL=true
GRAPH_MODE=classic
VITE_DEV_API_TARGET=http://127.0.0.1:8001
```

### staging (联调)

```bash
APP_ENV=staging
AUTH_MODE=jwt
AUTH_JWT_SECRET=xxxx
STORAGE_BACKEND=mysql
DATABASE_URL=mysql+asyncmy://zhenhu:pass@mysql:3306/zhenhu_staging
DEEPSEEK_API_KEY=sk-xxxx
MILVUS_HOST=milvus
REDIS_URL=redis://redis:6379/0
```

### production

```bash
APP_ENV=production
AUTH_MODE=oidc
AUTH_JWKS_URL=https://sso.hospital.com/.well-known/jwks.json
STORAGE_BACKEND=mysql
DATABASE_URL=mysql+asyncmy://zhenhu:pass@mysql:3306/zhenhu
DB_POOL_SIZE=50
DB_POOL_OVERFLOW=20
DEEPSEEK_API_KEY=sk-xxxx
MILVUS_HOST=milvus
NEO4J_URI=bolt://neo4j:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=xxxx
REDIS_URL=redis://redis:6379/0
CONTACT_ENCRYPTION_KEY=xxxx
LOG_LEVEL=WARNING
ALLOWED_HOSTS=zhenhu.hospital.com
MANAGEMENT_OPERATIONS_ENABLED=true
# OIDC/JWT claims 必须包含 zhenhu:admin:write 或 zhenhu:admin:*
GRAPH_MODE=classic
```
