## 三、后续知识治理候选项

以下项目是矩阵当前显示的知识覆盖空位，不表示系统功能缺失，也不应在未经过临床内容审核时自动补写。每次增补后应重建 RAG 索引并由对应学科负责人复核。

### 3.1 缺自护知识的病种 (12 个)

| 病种 | 优先级 | 说明 |
|------|:--:|------|
| hypertension | P1 | 高血压患者出院血压自测+饮食控制 |
| cad | P1 | 冠心病 PCI 术后自管+抗板药依从 |
| pneumonia | P2 | 肺炎出院后康复+排痰 |
| delirium | P3 | 老年谵妄家属照护指导 |
| hyperthyroidism | P1 | 甲亢用药依从+甲功复查 |
| cirrhosis | P1 | 肝硬化限钠+腹水监测+肝性脑病识别 |
| gi_bleeding | P1 | 消化道出血饮食+黑便识别 |
| aki | P1 | 肾损伤恢复期限钾+限蛋白 |
| hip_fracture | P1 | 髋部术后康复+防跌倒 |
| sepsis | P2 | 脓毒症后康复+体力恢复 |
| post_surgery | P2 | 术后伤口护理+拆线后注意事项 |
| severe_anemia | P2 | 贫血饮食补铁+B12 |

### 3.2 缺 RAG 疾病要点的病种 (8 个)

| 病种 | 说明 |
|------|------|
| atrial_fibrillation | 房颤的 CHA2DS2-VASc 评分、抗凝策略 |
| asthma | 哮喘阶梯治疗、急性发作处理 |
| pe | 肺栓塞 Wells 评分、PESI 分层 |
| delirium | 谵妄 CAM-ICU 评估、非药物管理 |
| hyperthyroidism | 甲亢 ATD 治疗、甲亢危象识别 |
| gi_bleeding | 消化道出血 Rockall/Blatchford 评分 |
| pancreatitis | 急性胰腺炎严重度分级、EN 时机 |
| severe_anemia | 贫血病因鉴别、输血指征 |

### 3.3 缺营养支持的病种 (13 个)

大部分非消化/非慢性病种缺营养支持知识。优先补: stroke(卒中吞咽障碍) / sepsis(脓毒症代谢) / cirrhosis(肝硬化限蛋白) / tumor_chemo(肿瘤恶液质)。
