# PoC 隔离区

本目录用于验证正式项目中高风险或跨层的业务假设。当前验证范围为：预置脱敏病例、确定性规则、模拟知识引用、医生审核、任务草稿、模拟发布、权限拒绝、审计追溯，以及受控 `.txt/.md/.pdf/.docx` 知识导入。

当前基线、已验证能力和后续边界见 [`docs/CONTEXT.md`](docs/CONTEXT.md)。

```powershell
npm run poc:serve
npm run poc:test
npm run poc:verify-embedding
```

首次执行嵌入验证或语义检索时会下载多语言模型到 `poc/.cache/`。模型不可用时，检索接口会明确返回 TF-IDF 降级策略，不会把降级结果伪装成语义检索。

## 迁移规则

PoC 通过不等于正式项目可上线。正式项目只能迁移已经验证的领域契约、状态机、测试场景和交互原则；真实身份权限、持久化、审计完整性、知识治理、运维与医院接口必须在正式项目中独立实现和验收。
